==============================================================
  پناهگاه — راهنمای کامل دپلوی روی VPS (اوبونتو ۲۲.۰۴ / ۲۴.۰۴)
==============================================================

مهم: همه مراحل «نصب» را تا وقتی اینترنت بین‌الملل وصل است (یا از طریق
میرور داخلی) انجام بده. بعد از نصب، برنامه به هیچ منبع خارجی نیاز ندارد
(فونت، CDN و ... ندارد) و فقط روی شبکه داخلی هم کار می‌کند.


--------------------------------------------------------------
۱) ورود به سرور و نصب پیش‌نیازها
--------------------------------------------------------------
  ssh root@IP_SERVER

  apt update
  apt install -y python3 python3-venv python3-pip nginx ufw unzip

اگر apt یا pip از سرور ایران کند/بسته بود، از میرور داخلی استفاده کن:
  pip install -i https://mirror-pypi.runflare.com/simple ...
(یا هر میرور PyPI داخلی دیگری که در دسترس است)


--------------------------------------------------------------
۲) آپلود پروژه
--------------------------------------------------------------
از کامپیوتر خودت:
  scp panahgah.zip root@IP_SERVER:/opt/

روی سرور:
  cd /opt
  unzip panahgah.zip
  cd /opt/panahgah


--------------------------------------------------------------
۳) ساخت محیط پایتون و نصب وابستگی‌ها
--------------------------------------------------------------
  cd /opt/panahgah
  python3 -m venv venv
  ./venv/bin/pip install --upgrade pip
  ./venv/bin/pip install -r requirements.txt

(اختیاری ولی توصیه‌شده) ذخیره‌ی پکیج‌ها برای نصب آفلاین در آینده:
  ./venv/bin/pip download -r requirements.txt -d /opt/wheels
  # بعداً: ./venv/bin/pip install --no-index --find-links /opt/wheels -r requirements.txt


--------------------------------------------------------------
۴) ساخت حساب مالک
--------------------------------------------------------------
نقش «مالک» به نام کاربری  mahbod  تعلق دارد (قابل تغییر با متغیر
OWNER_USERNAME در فایل سرویس). مالک را این‌طور بساز:

  cd /opt/panahgah
  ./venv/bin/python manage.py admin mahbod "MyStrongPass123" "نام من"

هشدار: اگر کاربری با نام mahbod از قبل هست، این دستور رمزش را عوض می‌کند.

چهار سطح دسترسی:
  مالک (mahbod) : همه‌چیز — ساخت/ویرایش/حذف کاربر، افزودن ادمین جدید و تغییر
                  سطح‌ها، ساخت/ویرایش/حذف گروه، خالی کردن تاریخچه‌ی گروه،
                  مدیریت فضا، حذف هر پیام، آپلود و حذف در سرگرمی، افزودن/حذف لینک.
  ادمین         : حذف پیام‌ها، افزودن کاربر (عادی یا سطح ۲)، ویرایش/ریست رمز
                  کاربران عادی و سطح ۲، آپلود و حذف محتوا و لینک در سرگرمی.
  کاربر سطح ۲   : دسترسی عادی + آپلود محتوا و افزودن لینک در سرگرمی (حذف فقط
                  موارد خودش).
  کاربر عادی    : پیام، فایل، ویس، ریپلای و حذف پیام‌های خودش.

دستورهای دیگر:
  ./venv/bin/python manage.py list
  ./venv/bin/python manage.py passwd USERNAME NEWPASS
  ./venv/bin/python manage.py user USERNAME PASS "نام"
  ./venv/bin/python manage.py uploader USERNAME PASS "نام"     (سطح ۲)


--------------------------------------------------------------
۵) اجرای دائمی با systemd + gunicorn
--------------------------------------------------------------
یوزر مخصوص سرویس و دسترسی‌ها:
  useradd -r -s /usr/sbin/nologin panahgah
  chown -R panahgah:panahgah /opt/panahgah

فایل سرویس را بساز:
  nano /etc/systemd/system/panahgah.service

محتوا:

  [Unit]
  Description=Panahgah Messenger
  After=network.target

  [Service]
  User=panahgah
  Group=panahgah
  WorkingDirectory=/opt/panahgah
  Environment="MAX_UPLOAD_MB=3072"
  ExecStart=/opt/panahgah/venv/bin/gunicorn -w 3 -k gthread --threads 8 --timeout 900 -b 127.0.0.1:8000 app:app
  Restart=always
  RestartSec=3

  [Install]
  WantedBy=multi-user.target

فعال‌سازی:
  systemctl daemon-reload
  systemctl enable --now panahgah
  systemctl status panahgah
  # لاگ زنده:  journalctl -u panahgah -f

توضیح: -w 3 یعنی سه پردازه. اگر سرور فقط ۱ هسته دارد -w 2 بگذار.
(سیستم گفتگو با polling کار می‌کند و به sticky session نیاز ندارد.)


--------------------------------------------------------------
۶) تنظیم Nginx
--------------------------------------------------------------
  nano /etc/nginx/sites-available/panahgah

محتوا:

  server {
      listen 80 default_server;
      listen [::]:80 default_server;
      server_name _;

      client_max_body_size 3g;
      client_body_timeout 900s;
      proxy_read_timeout 900s;
      proxy_send_timeout 900s;
      proxy_request_buffering off;

      location /static/ {
          alias /opt/panahgah/static/;
          expires 7d;
      }

      location / {
          proxy_pass http://127.0.0.1:8000;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
          proxy_buffering off;
      }
  }

فعال‌سازی:
  rm -f /etc/nginx/sites-enabled/default
  ln -s /etc/nginx/sites-available/panahgah /etc/nginx/sites-enabled/panahgah
  nginx -t
  systemctl restart nginx

حالا آدرس  http://IP_SERVER  را در مرورگر باز کن و وارد شو.


--------------------------------------------------------------
۷) فایروال
--------------------------------------------------------------
  ufw allow OpenSSH
  ufw allow 80/tcp
  ufw allow 443/tcp
  ufw enable

(پورت ۸۰۰۰ فقط روی localhost باز است و بیرون در دسترس نیست.)


--------------------------------------------------------------
۸) HTTPS (اختیاری)
--------------------------------------------------------------
- بدون دامنه: با IP و HTTP هم کامل کار می‌کند.
- Let's Encrypt برای صدور/تمدید گواهی به اینترنت بین‌الملل و دامنه نیاز دارد؛
  در زمان قطعی کار نمی‌کند. اگر گواهی تجاری/داخلی داری و HTTPS راه انداختی:
  در فایل سرویس این خط را اضافه کن تا کوکی‌ها امن شوند:
      Environment="HTTPS=1"
  سپس: systemctl daemon-reload && systemctl restart panahgah
- اگر HTTPS نداری این متغیر را نگذار (وگرنه ورود کار نمی‌کند).


--------------------------------------------------------------
۹) استفاده
--------------------------------------------------------------
- مدیر: بخش «مدیریت» → ساخت کاربر (نام کاربری + رمز) → رمز را به دوستت بده.
- مدیر: بخش «مدیریت» → ساخت گروه، انتخاب اعضا. بعداً با «ویرایش» اعضا را
  کم/زیاد کن. فقط مدیر گروه می‌سازد.
- همه: «پیام جدید» → نام کاربری طرف مقابل → شروع گفتگو.
- پاسخ (ریپلای) / حذف: روی حباب پیام بزن، دکمه‌ها ظاهر می‌شوند.
- ارسال فایل: دکمه‌ی گیره، کشیدن و رها کردن، یا paste تصویر.
- سرگرمی: صفحه‌ی اصلی چند باکس رنگی است: موزیک، پادکست، فیلم و سریال، کتاب PDF و
  لینک‌ها. مالک، ادمین و کاربر سطح ۲ آپلود می‌کنند؛ زیر هر مورد نوشته می‌شود «توسط ...».
  می‌توانی چند فایل را یکجا آپلود کنی و در «دسته‌بندی» نام آلبوم/سریال را
  بنویسی تا گروه‌بندی شوند.
- فیلم: فرمت‌های mp4 (H.264/AAC) و webm در همه‌ی مرورگرها پخش می‌شوند.
  mkv در بعضی مرورگرها پخش نمی‌شود؛ قبلش به mp4 تبدیل کن:
      ffmpeg -i in.mkv -c:v libx264 -c:a aac -movflags +faststart out.mp4
- لینک‌ها (در سرگرمی): مالک، ادمین و کاربر سطح ۲ می‌توانند آدرس سایت‌هایی را که روی
  نت ملی (بدون VPN) باز می‌شوند با یک عنوان ثبت کنند؛ همه می‌بینند و با یک کلیک باز یا
  کپی می‌کنند. فقط http/https پذیرفته می‌شود؛ اگر کسی بدون پیشوند بنویسد https:// اضافه می‌شود.
- سین (خوانده شدن): زیر پیام‌های خودت ✓ یعنی ارسال شد و ✓✓ سبز یعنی دیده شد. در گروه،
  ✓✓ خاکستری یعنی بعضی‌ها دیده‌اند و سبز یعنی همه. با زدن روی پیام خودت در گروه و دکمه‌ی
  «دیده‌شده» اسامی را می‌بینی. در لیست گفتگوها هم برای آخرین پیام نشان داده می‌شود.
- پیام خصوصی از داخل گروه: روی اسم عضو در لیست اعضا (بالای گروه) یا روی اسم فرستنده‌ی
  پیام بزن تا پیوی با او باز شود.
- نصب روی گوشی: در مرورگر «Add to Home Screen» بزن.


--------------------------------------------------------------
۱۰) فونت وزیرمتن (اختیاری، برای ظاهر بهتر)
--------------------------------------------------------------
فایل Vazirmatn-Regular.woff2 را دانلود کن و با نام زیر بگذار:
  /opt/panahgah/static/Vazirmatn.woff2
بدون آن هم از فونت‌های سیستم (Tahoma و ...) استفاده می‌شود.


--------------------------------------------------------------
۱۱) بکاپ و بازیابی
--------------------------------------------------------------
همه‌ی داده‌ها در پوشه‌ی /opt/panahgah/data است (دیتابیس، فایل‌ها، کلید نشست).
بکاپ:
  systemctl stop panahgah
  tar czf /root/panahgah-backup-$(date +%F).tar.gz -C /opt/panahgah data
  systemctl start panahgah
بازیابی:
  systemctl stop panahgah
  tar xzf BACKUP.tar.gz -C /opt/panahgah
  chown -R panahgah:panahgah /opt/panahgah/data
  systemctl start panahgah

به‌روزرسانی کد: فایل‌های app.py و static/ را جایگزین کن (پوشه‌ی data را دست
نزن) و بزن:  systemctl restart panahgah


--------------------------------------------------------------
۱۲) عیب‌یابی
--------------------------------------------------------------
- صفحه باز نمی‌شود: systemctl status panahgah  و  nginx -t
- خطای 413 هنگام آپلود: مقدار client_max_body_size و MAX_UPLOAD_MB را بالا ببر.
- آپلود فایل بزرگ قطع می‌شود: فضای دیسک را چک کن (df -h) و timeoutها را بالا ببر.
- بعد از ورود دوباره به صفحه ورود برمی‌گردد: اگر HTTPS=1 گذاشته‌ای ولی سایت
  با http باز می‌شود، آن را بردار.
- رمز مدیر را فراموش کردی:
  cd /opt/panahgah && ./venv/bin/python manage.py passwd MYUSER NEWPASS
- تست دسترسی از دید کاربر داخلی: از یک گوشی با اینترنت ملی/داخلی آدرس
  http://IP_SERVER را باز کن و مطمئن شو بدون VPN باز می‌شود.

--------------------------------------------------------------
۱۳) ضبط ویس و HTTPS
--------------------------------------------------------------
مرورگرها اجازه‌ی میکروفون را فقط در صفحه‌ی HTTPS می‌دهند. روی HTTP ساده،
دکمه‌ی ویس به‌جای ضبط مستقیم، برنامه‌ی ضبط صدای خود گوشی را باز می‌کند
(که آن هم کار می‌کند). برای ضبط مستقیم، HTTPS راه بینداز:

الف) با دامنه: قبل از قطعی certbot بگیر (گواهی ۹۰ روزه است و تمدیدش به
    اینترنت نیاز دارد):
      apt install -y certbot python3-certbot-nginx
      certbot --nginx -d YOUR.DOMAIN

ب) بدون دامنه، گواهی خودامضا (۱۰ سال اعتبار؛ هر کاربر یک بار باید در
    هشدار مرورگر «Advanced → Proceed» بزند):
      openssl req -x509 -nodes -newkey rsa:2048 -days 3650 \
        -keyout /etc/ssl/private/panahgah.key -out /etc/ssl/certs/panahgah.crt \
        -subj "/CN=IP_SERVER" -addext "subjectAltName=IP:IP_SERVER"
    در بلوک server فایل nginx این‌ها را اضافه کن (و listen 80 را نگه دار):
      listen 443 ssl;
      ssl_certificate /etc/ssl/certs/panahgah.crt;
      ssl_certificate_key /etc/ssl/private/panahgah.key;
    سپس:  nginx -t && systemctl reload nginx
    اگر روی گوشی‌ها میکروفون با گواهی خودامضا کار نکرد، از ضبط‌کننده‌ی
    جایگزین استفاده می‌شود.

بعد از فعال شدن HTTPS در فایل سرویس بگذار:  Environment="HTTPS=1"


--------------------------------------------------------------
۱۴) مدیریت فضای سرور (مهم)
--------------------------------------------------------------
محافظ‌ها (همه خودکار):
- وقتی فضای آزاد دیسک کمتر از ۴ گیگابایت شود، آپلود هر فایلی در هیچ
  بخشی (چت، ویس، سرگرمی، عکس پروفایل) پذیرفته نمی‌شود. پیام متنی همچنان
  کار می‌کند. (مقدار با MIN_FREE_GB در فایل سرویس قابل تغییر است.)
- سقف حجم هر فایل و سهمیه‌ی هر کاربر (پیش‌فرض: هر فایل چت ۱۰۰MB، سهمیه‌ی
  فایل‌های چت هر کاربر ۱GB، هر فایل سرگرمی ۲GB، سهمیه‌ی سرگرمی کاربر
  سطح ۲ پنج گیگ). مالک از هر دو معاف است ولی قفل ۴ گیگ برای او هم هست.
- پاک‌سازی اضطراری: اگر فضا از ۴GB کمتر شد، قدیمی‌ترین فایل‌های چت پاک
  می‌شوند (متن پیام‌ها می‌ماند و جایش «فایل حذف شد» نشان داده می‌شود)
  تا فضا به ۵GB برسد. سرگرمی هرگز خودکار پاک نمی‌شود.
- اختیاری: حذف خودکار فایل‌های چت قدیمی‌تر از N روز.
- هر ساعت فایل‌های بی‌صاحب (آپلودهای نیمه‌کاره) پاک می‌شوند.

پنل مالک → «مدیریت فضا»:
  نمودار دیسک، مصرف هر بخش و هر کاربر و هر گروه، تنظیم سقف‌ها،
  پاک‌سازی فایل‌های قدیمی‌تر از N روز، حذف فایل‌های چت یک کاربر،
  خالی کردن تاریخچه‌ی هر گروه، و دکمه‌ی «بهینه‌سازی» (فایل‌های اضافه +
  فشرده‌سازی دیتابیس). اگر فضا کم باشد، مالک موقع ورود هشدار می‌بیند.

کارهای دستی روی سرور (یک بار انجام بده):
  # ۱) فایل ذخیره‌ی اضطراری ۲GB؛ اگر دیسک پر شد پاکش کن تا سرور بالا بیاید
  fallocate -l 2G /opt/panahgah/BALLAST.bin
  #    (در حالت اضطراری:  rm /opt/panahgah/BALLAST.bin)

  # ۲) محدود کردن لاگ‌های سیستم
  journalctl --vacuum-size=200M
  nano /etc/systemd/journald.conf      # بگذار:  SystemMaxUse=200M
  systemctl restart systemd-journald

  # ۳) پاک کردن کش بسته‌ها
  apt clean

  # ۴) چک فضا
  df -h /          و          du -sh /opt/panahgah/data/uploads/*

مهم: client_max_body_size در nginx (۳g) باید از بزرگ‌ترین سقف حجمی که در
پنل می‌گذاری بیشتر باشد.


--------------------------------------------------------------
۱۵) به‌روزرسانی به این نسخه (دپلوی مجدد)
--------------------------------------------------------------
دیتابیس خودش ارتقا می‌یابد و اطلاعات قبلی پاک نمی‌شود. ادمین‌های قبلی
«ادمین» می‌مانند ولی ساخت گروه از این نسخه فقط برای مالک است.

۱) بکاپ بگیر (بخش ۱۱).
۲) فایل جدید را بفرست و باز کن، بدون دست زدن به data و venv:
     scp panahgah.zip root@IP_SERVER:/opt/
     cd /opt && unzip -o panahgah.zip -x "panahgah/data/*" "panahgah/venv/*"
     chown -R panahgah:panahgah /opt/panahgah
۳) اگر حساب mahbod نداری، بخش ۴ را اجرا کن.
۴) کارهای دستی بخش ۱۴ (BALLAST و لاگ‌ها) را انجام بده.
۵) ری‌استارت:  systemctl restart panahgah
۶) مرورگر: Hard Refresh (Ctrl+F5).
۷) وارد شو → «مدیریت» → «مدیریت فضا» → سقف‌ها را مطابق دیسک سرورت تنظیم کن.
فایل‌های سرویس و nginx خارج از پوشه‌ی پروژه‌اند و عوض نمی‌شوند
(اگر پورت ۸۰۰۱ گذاشته‌ای دست نزن).

نکات امنیتی:
- رمز مدیر را قوی بگذار و کلید secret.key را جایی منتشر نکن.
- پیام‌ها رمزنگاری سرتاسری نیستند؛ مدیر سرور به دیتابیس دسترسی دارد.
  فقط افراد مورد اعتماد را عضو کن.

--------------------------------------------------------------
۱۶) تغییرات این نسخه
--------------------------------------------------------------
- سرگرمی: صفحه‌ی باکس‌های رنگی بجای زبانه‌ها + بخش جدید «لینک‌ها».
- زیر هر محتوای سرگرمی و هر لینک، نام آپلودکننده نوشته می‌شود (برای مواردی که قبل از این
  نسخه آپلود شده‌اند و ثبت‌کننده‌شان ثبت نشده، چیزی نشان داده نمی‌شود).
- سین پیام‌ها (پیوی و گروه).
- باز شدن پیوی از لیست اعضای گروه و از روی نام فرستنده.
- رفع مشکل تایپ نام کاربری روی ویندوز: اگر کیبورد روی فارسی بود، حروف فارسی خودکار به
  معادل انگلیسی همان کلید تبدیل می‌شوند (مثلاً «ذخذ» ← bob) و ارقام فارسی به انگلیسی.
  همین تبدیل سمت سرور هم برای ورود و شروع گفتگو انجام می‌شود.
- جدول جدید links هنگام اولین اجرا خودکار ساخته می‌شود؛ نیازی به مایگریشن دستی نیست.
  برای به‌روزرسانی طبق بخش ۱۵ عمل کن و حتماً Hard Refresh (Ctrl+F5) بزن.


--------------------------------------------------------------
۱۷) کانال‌ها (جدید)
--------------------------------------------------------------
- فقط مالک کانال می‌سازد: «مدیریت» ← «کانال‌ها». نام را بنویس و برای هر کاربر دو تیک بزن:
    «عضو»        : کانال را در لیست گفتگوهایش می‌بیند و پیام‌ها را می‌خواند.
    «پیام‌دهنده»  : علاوه بر خواندن، می‌تواند در کانال بنویسد (متن، فایل، ویس، ریپلای).
  (تیک پیام‌دهنده خودکار او را عضو هم می‌کند.) مالک همیشه می‌تواند پیام بدهد.
- اعضای بدون اجازه به‌جای نوار پیام، یک اعلان «فقط افراد مجاز می‌توانند پیام بدهند» می‌بینند
  و سرور هم ارسال از طرف آن‌ها را رد می‌کند (۴۰۳).
- مالک هر زمان با «ویرایش» اعضا و پیام‌دهنده‌ها را عوض می‌کند؛ تغییر مجوز فوری اعمال می‌شود.
  حذف از لیست اعضا، دسترسی خواندن را هم می‌گیرد.
- ادمین‌ها می‌توانند پیام‌های کانال را حذف کنند. مالک می‌تواند تاریخچه را خالی یا کانال را حذف کند.
- ستون جدید can_post در جدول members هنگام اولین اجرا خودکار اضافه می‌شود؛ گروه‌ها و
  پیوی‌های قبلی بدون تغییر کار می‌کنند. به‌روزرسانی طبق بخش ۱۵ و بعد Hard Refresh.


--------------------------------------------------------------
۱۸) پنل مدیریت مرتب‌تر، پروفایل گروه/کانال و تگ کردن (جدید)
--------------------------------------------------------------
- پنل «مدیریت» دیگر فرم باز ندارد. بالای صفحه دکمه‌های «ایجاد کاربر»، «ایجاد گروه»،
  «ایجاد کانال» و «مدیریت فضا» هست (سه‌تای آخر فقط برای مالک). هر دکمه فرمش را در یک
  پنجره‌ی کوچک باز می‌کند. «مدیریت فضا» با هر بار زدن باز/بسته می‌شود.
  زیر دکمه‌ها فقط لیست کاربران، گروه‌ها و کانال‌ها (همراه با عکس) دیده می‌شود.
- پروفایل گروه و کانال (فقط مالک): هنگام ایجاد یا «ویرایش» می‌توانی عکس و توضیحات بگذاری.
  عکس در لیست گفتگوها، بالای گفتگو و پنجره‌ی اطلاعات (با زدن روی نام گروه/کانال) نمایش داده
  می‌شود و توضیحات هم همان‌جا نشان داده می‌شود. مالک از همان پنجره‌ی اطلاعات هم می‌تواند
  عکس را عوض یا حذف کند. عکس‌ها در data/uploads/avatars کنار عکس کاربران ذخیره می‌شوند
  (حداکثر ۵ مگابایت؛ قبل از ارسال، مربع و کوچک می‌شوند) و با حذف گروه پاک می‌شوند.
- تگ کردن در گروه (مثل تلگرام): در گروه، کلید @ را بزن تا لیست اعضا بیاید؛ با تایپ ادامه‌ی
  نام کاربری یا نام نمایشی (فارسی هم جواب می‌دهد) فیلتر می‌شود. با کلیک/لمس یا فلش‌ها +
  Enter/Tab انتخاب کن. در پیام، @نام‌کاربری رنگی دیده می‌شود و با زدن روی آن، پیوی با او باز
  می‌شود. اگر تو تگ شده باشی، تگ تو هایلایت می‌شود و در لیست گفتگوها تا وقتی گروه را نخوانده‌ای
  نشان سبز «@» کنار تعداد پیام‌های خوانده‌نشده می‌ماند. فقط اعضای همان گروه تگ می‌شوند.
- دو ستون جدید chats.avatar و chats.about هنگام اولین اجرا خودکار ساخته می‌شوند؛ مایگریشن
  دستی لازم نیست. به‌روزرسانی طبق بخش ۱۵ و بعد Hard Refresh (Ctrl+F5).


--------------------------------------------------------------
۱۹) اصلاحات این نسخه (دکمه‌ی بازگشت، کشویی‌ها، پخش سریع، جلو/عقب، لوگو)
--------------------------------------------------------------
- دکمه‌ی بازگشت گوشی: یک بار = یک مرحله عقب در خود برنامه (بستن پنجره/فیلم، خروج از گفتگو،
  برگشت از یک دسته‌ی سرگرمی به لیست دسته‌ها، برگشت از سرگرمی/مدیریت به گفتگوها).
  روی صفحه‌ی اصلی، بار اول پیام «برای خروج، یک بار دیگر بزن» می‌آید و دو بار پشت‌سرهم از سایت خارج می‌شود.
- سرگرمی: موزیک، پادکست، فیلم و کتاب به‌صورت کشویی‌اند (نام دسته/خواننده + تعداد؛ با لمس باز و بسته می‌شود).
  هنگام جستجو، دسته‌های مطابق خودکار باز می‌شوند.
- جلو/عقب کردن موزیک و پادکست در موبایل: نوار پخش در موبایل پنهان بود و حالا نمایش داده می‌شود؛
  دکمه‌های ۱۰ ثانیه عقب/جلو هم اضافه شد (و روی صفحه‌ی قفل گوشی هم کار می‌کند).
- شروع کند فیلم: علت معمول، قرار گرفتن اطلاعات پخش (moov) در انتهای فایل MP4 است؛ مرورگر باید
  آن را بگیرد تا پخش را شروع کند. از این نسخه، هر mp4/m4v/mov/m4a که آپلود شود (چت و سرگرمی) خودکار
  و بدون افت کیفیت اصلاح می‌شود. برای فایل‌هایی که قبلاً آپلود شده‌اند یک بار اجرا کن:
      cd /opt/panahgah && ./venv/bin/python manage.py faststart
  (می‌تواند چند دقیقه طول بکشد؛ جای خالی معادل حجم بزرگ‌ترین فایل لازم است.)
  توجه: فرمت mkv و فایل‌های H.265 در بعضی مرورگرها/گوشی‌ها کند یا بی‌صدا پخش می‌شوند؛
  بهتر است قبل از آپلود با ffmpeg به mp4 (H.264/AAC) تبدیل شوند (دستورش در بخش ۹).
- (اختیاری ولی توصیه‌شده) سرو فایل‌ها توسط خود nginx تا پایتون درگیر ارسال فیلم نشود و پخش/جلو-عقب
  سریع‌تر شود. احراز هویت همچنان توسط برنامه انجام می‌شود:
  ۱) در فایل nginx داخل بلوک server این را اضافه کن:
        location /_protected/ {
            internal;
            alias /opt/panahgah/data/uploads/;
        }
  ۲) در فایل سرویس اضافه کن:   Environment="ACCEL_REDIRECT=1"
  ۳) nginx -t && systemctl reload nginx && systemctl daemon-reload && systemctl restart panahgah
  (اگر پوشه‌ی داده را با PANAHGAH_DATA جای دیگری گذاشته‌ای، alias را به همان مسیر/uploads/ تغییر بده.)
- لوگوی نوشتاری «Panahgah» با فونت دست‌نویس Grand Hotel (مجوز OFL، فایل static/PanahBrand.woff2)
  در بالای صفحه‌های گفتگو، سرگرمی، مدیریت و صفحه‌ی ورود. فایل محلی است و به اینترنت نیاز ندارد.
- به‌روزرسانی: طبق بخش ۱۵، بعد systemctl restart panahgah و در مرورگر Hard Refresh.


--------------------------------------------------------------
۲۰) پورت ۸۰۰۱ (جدید)
--------------------------------------------------------------
از این نسخه install.sh برنامه را مستقیم روی پورت ۸۰۰۱ اجرا می‌کند و به nginx و پورت ۸۰ دست نمی‌زند.
آدرس:  http://IP_SERVER:8001
(هر جای این راهنما که ۸۰۰۰ یا ۸۰۰۱ و nginx آمده، برای نصب دستی قدیمی است.)
اگر بخواهی پورت دیگری باشد:  PORT=8002 bash install.sh
